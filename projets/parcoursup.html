La questionThe question

Chaque année, des centaines de milliers de lycéens formulent leurs vœux sur Parcoursup. Certaines formations reçoivent des dizaines de candidatures par place, d'autres peinent à se remplir. L'objectif : mesurer cette tension, suivre son évolution et identifier les facteurs qui l'expliquent (filière, sélectivité, territoire, statut public ou privé).

Every year, hundreds of thousands of students apply through Parcoursup. Some programmes receive dozens of applications per seat, while others struggle to fill up. The goal: measure this pressure, track how it changes over time and identify the factors that explain it (field, selectivity, region, public or private status).

Les donnéesThe data

Fichiers open data Parcoursup du ministère de l'Enseignement supérieur : une ligne par formation et par session, 118 variables (capacité, candidats, propositions, admis, profils des candidats, boursiers, etc.).

Parcoursup open data files from the French Ministry of Higher Education: one row per programme and per session, with 118 variables (capacity, applicants, offers, admissions, applicant profiles, scholarship holders, etc.).

Principaux défis : formats de nombres hétérogènes, pourcentages hors bornes, colonnes en doublon, valeurs extrêmes (formations à très faible capacité) et noms de colonnes qui changent d'une année à l'autre.

Main challenges: inconsistent number formats, out-of-range percentages, duplicated columns, extreme values (programmes with very small capacity) and column names that change from one year to the next.

La méthodeMethod

  1. Nettoyage automatisé en R : détection du séparateur, conversion des types, suppression des doublons, pourcentages bornés à [0, 100], contrôles qualité.
  2. Automated cleaning in R: delimiter detection, type conversion, duplicate removal, percentages bounded to [0, 100], quality checks.
  3. Construction des KPI : pression (candidats / capacité), taux de remplissage (admis / capacité), taux de proposition, taux d'acceptation, détection du surbooking.
  4. KPI design: pressure (applicants / capacity), fill rate (admitted / capacity), offer rate, acceptance rate, overbooking flag.
  5. Traitement des valeurs extrêmes : winsorisation à 1 % pour éviter que quelques formations minuscules faussent les analyses.
  6. Outlier handling: 1% winsorisation so that a few tiny programmes do not distort the analysis.
  7. Analyse multivariée : ACP / AFDM puis classification (CAH et k-means) pour dégager des profils types de formations.
  8. Multivariate analysis: PCA / FAMD followed by clustering (hierarchical clustering and k-means) to identify typical programme profiles.
  9. Modélisation : régression linéaire sur log(1 + pression), puis Random Forest et XGBoost, et restitution dans des dashboards R Shiny.
  10. Modelling: linear regression on log(1 + pressure), then Random Forest and XGBoost, presented in R Shiny dashboards.

add_kpis <- function(df) {
  df %>% mutate(
    pression    = if_else(capacite > 0, candidats_total / capacite, NA_real_),
    remplissage = if_else(capacite > 0, admis_total / capacite, NA_real_),
    taux_accept = if_else(propositions > 0, admis_total / propositions, NA_real_)
  )
}

winsor <- function(x, p = 0.01) {
  q <- quantile(x, probs = c(p, 1 - p), na.rm = TRUE)
  pmin(pmax(x, q[1]), q[2])
}

The number of seats stays stable (around 33,000 per year), while demand peaked in 2023 at over 401,000 applications. Overall pressure stays around 12 applications per seat. Meanwhile, the fill rate dropped from 90.6% in 2020 to 84.2% in 2024: many applicants, yet not every seat is filled.

À retenir : les formations les plus tendues sont les IFSI (soins infirmiers, 25 candidatures par place), PASS et CPGE. Key takeaway: the highest-pressure programmes are nursing schools (IFSI, 25 applications per seat), PASS (medicine) and CPGE (preparatory classes). BTS programmes are by far the most numerous (283) but much less competitive (7.5). Pressure is mainly driven by programme type and selectivity, far more than by the size of the offer.

Limites et leçonsLimits and lessons

Une fuite de données détectée. Mes premiers modèles Random Forest et XGBoost affichaient des scores presque parfaits. En analysant l'importance des variables, j'ai constaté qu'ils utilisaient le nombre de candidats et la capacité, c'est-à-dire les éléments qui servent à calculer la pression : le modèle recalculait la réponse au lieu de la prédire. Leçon retenue : ne jamais faire confiance à un score trop beau sans vérifier les variables utilisées.

Data leakage detected. My first Random Forest and XGBoost models showed near-perfect scores. By analysing feature importance, I found they were using the number of applicants and the capacity, the very inputs used to compute pressure: the model was recalculating the answer instead of predicting it. Lesson learned: never trust a score that looks too good without checking which variables drive it.

  • Le modèle explicatif retenu (régression linéaire sur les données nationales 2024 : filière, sélectivité, région, statut, capacité) explique environ 34 % de la variance (R² = 0,34) : la tension dépend aussi de facteurs absents des données (réputation, localisation fine, débouchés).
  • The retained explanatory model (linear regression on 2024 national data: field, selectivity, region, status, capacity) explains about 34% of the variance (R² = 0.34): pressure also depends on factors that are not in the data (reputation, precise location, career prospects).
  • Une même personne peut postuler à plusieurs formations : la « pression » mesure une demande de vœux, pas un nombre d'individus.
  • One student can apply to several programmes: "pressure" measures applications, not individual people.
  • Prochaine étape : reconstruire les modèles prédictifs uniquement avec des variables connues avant la campagne (approche « ex ante »).
  • Next step: rebuild the predictive models using only variables known before the admission campaign (an "ex ante" approach).
